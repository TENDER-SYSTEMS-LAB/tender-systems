## Convention

Records are named `DEC-NNN-short-slug.md` and carry the same frontmatter as Lab pages: `status`, `attribution`, `updated`, `sources`.

A decision belongs here only if it would still apply after any individual project ended. Otherwise it belongs in that project's Lab or implementation repository — see [[DEC-002-decision-placement]].
